API Config Detector

自动检测 AI API 协议，30 秒生成 OpenClaw 配置。
支持 Anthropic、OpenAI 及所有兼容协议。

开始检测 →

为什么需要它？

⚡

自动检测协议

并发测试 Anthropic Messages、OpenAI Completions 等 6 种协议变体，自动选择最快的成功结果。

🎯

零配置错误

不用猜 API 路径、认证方式、请求格式。输入 URL 和 Key，直接得到可用配置。

📋

一键复制

生成完整的 openclaw.json 配置片段，包含 models.providers 和 agents.defaults.model。

工作原理

1

输入 API 信息

提供 Provider Name、Base URL、API Key 和测试模型（可选）。

2

并发协议检测

同时测试 6 种协议变体：Anthropic Messages（/v1/messages 和 /messages）、OpenAI Completions（/v1/chat/completions 和 /chat/completions）、无认证头、OpenAI Responses。

3

智能选择最优结果

如果测试模型是 Claude → 优先 Anthropic 协议；如果是 GPT → 优先 OpenAI 协议。相同协议选延迟最低的。

4

生成配置并复制

输出完整的 JSON 配置，直接粘贴到 ~/.openclaw/openclaw.json 即可使用。

{ "models": { "providers": { "my-provider": { "baseUrl": "https://api.example.com", "apiKey": "sk-xxx", "api": "anthropic-messages", "models": [...] } } }, "agents": { "defaults": { "model": "my-provider/claude-sonnet-4-6" } } }

命令行使用

node detect.js <baseUrl> <apiKey> [testModel] [providerName] # 示例 node detect.js https://api.anthropic.com sk-ant-xxx claude-sonnet-4-6 anthropic # JSON 输出（进度到 stderr，配置到 stdout） node detect.js https://api.anthropic.com sk-ant-xxx --json
